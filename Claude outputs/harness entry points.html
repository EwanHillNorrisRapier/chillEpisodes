Entry points, by reach

What a level means. Level 1 is what the entry point touches itself. Level 2 is what those objects touch that nothing at level 1 already reached, and so on. An object appears once, at the first level that reaches it, with every route into it listed underneath.

Every object is reachable. All 50 appear in at least one of these fifteen closures, so nothing in the deployment is stranded.

One blind spot. A procedure invoked from a graph node's own SQL lives in CSPScheduledItemString as data, not as code, so no analysis of the harness source can see it. That is exactly how CSPTableCopy, CSPTruncateTable and CSPValidateSourceRecords are meant to be reached, which is why they appear here as entry points rather than inside the engine's closure.
